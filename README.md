# Portfolio Tools

สองเครื่องมือแยกกันในโปรเจกต์เดียว สลับที่หัวเว็บ: **แถบสารบัญ** (`#/`) และ **Quote Page Maker** (`#/quote`)

## Portfolio Tab Maker

เว็บแอปทำหน้าพอร์ตโฟลิโอ A4 พร้อมแถบสารบัญด้านข้าง แล้วบันทึกเป็น PNG 2480×3508 px (300 DPI)
Vue 3 + Vite + TypeScript, html-to-image, jszip, ฟอนต์ @fontsource (ฝังในโปรเจกต์ ไม่ใช้ CDN)

## ใช้งาน
```
npm install
npm run dev          # http://localhost:5173
npm run build        # type-check + build
npm run test:e2e     # ต้องเปิด npm run dev ไว้ ตรวจขนาด PNG / alpha / ZIP และเก็บภาพลง docs/
```
(ครั้งแรกของ e2e: `npx playwright install chromium`)

## โครงสร้าง
- `src/components/PageCanvas.vue` หน้า 1240×1754 px คงที่ ใช้ทั้งพรีวิวและ export
- `src/export.ts` mount PageCanvas แบบไม่มี transform นอกจอ → html-to-image (warm-up 1 รอบ, pixelRatio 2)
- `src/store.ts` state + localStorage, `src/presets.ts` ชุดสี, `src/App.vue` UI
- `tests/e2e.mjs`, `sample/background.jpg` (ดึงจาก side-tabs-preview.html), `docs/` screenshot ผลลัพธ์

## ข้อตัดสินใจที่สเปกคลุมเครือ (เลือกแบบง่ายสุด)
- แถบวาดอยู่ในหน้า ชิดขอบ; มุมโค้งอยู่ด้านที่หันเข้าหาเนื้อหา; แถบ active กว้าง 1.36× ของแถบอื่น (ค่าคงที่)
- แถบมีเฉพาะชื่อไทย (ตัวหนา เขียนแนวตั้ง) ไม่มีชื่ออังกฤษ
- แต่ละแถบความสูงเท่ากัน ชื่อยาวมากจะล้นแถบ ให้ลดขนาดตัวอักษรหรือเพิ่มความสูงรวม
- เลขลำดับ: ช่องว่าง = ใส่อัตโนมัติ 01, 02, …
- ชุดสีเปลี่ยนทั้งสีแถบ ตัวอักษร และสีทอง; สีพื้นแถบเป็นรายแถบแก้ได้ภายหลัง
- รูปอัปโหลดถูกย่อให้ด้านยาวไม่เกิน 3508 px และเก็บเป็น JPEG data URL; ถ้าใหญ่เกินโควตา localStorage จะเตือนให้ใช้ไฟล์ .json
- ชื่อไฟล์ ZIP: `NN-ชื่อไทย.png`
- กรอบประสีแดงในพรีวิวคือพื้นที่แถบ (ไม่ติดไปกับไฟล์ export); เปิด/ปิดได้

## Quote Page Maker (`#/quote`)
ตัวแก้ไขหน้าคำคม A4 แบบองค์ประกอบ (ข้อความ รูป รูปทรง เครื่องหมายคำพูด ลายตกแต่ง) ลาก/ย่อขยาย/หมุน/snap, undo-redo 50 ขั้น, 6 template, 6 ชุดสี (+ชุดสีของตัวเอง), หลายหน้า,
export PNG (A4 300 DPI / A4 150 DPI / 1080×1350), พื้นโปร่งใส, ZIP

คีย์ลัด: ลูกศร 1px, Shift+ลูกศร 10px, Delete, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z (หรือ Ctrl+Y), Ctrl/Cmd+D, Shift ตอนย่อขยายคงสัดส่วน / ตอนหมุน snap 15°

### โครงสร้าง
- `src/shared/export.ts` ตัวช่วยกลาง: โหลดฟอนต์, mount นอกจอ, html-to-image (วอร์มอัพ 1 รอบ), อ่านรูป -> data URL (ใช้ร่วมกับเครื่องมือแถบ)
- `src/quote/` โมดูลทั้งหมด: `store.ts` (state, history, localStorage `quote-maker:v1`, ไฟล์ `.json` ของตัวเอง), `ElementView.vue` (วาดองค์ประกอบ), `QuotePage.vue` (หน้า 1240×1754 ไม่มี UI), `QuoteCanvas.vue` (overlay ตัวแก้ไข), `templates.ts`, `theme.ts`, `export.ts`
- สีในองค์ประกอบเป็น token (`@text`, `@accent` …) แปลงตามชุดสีของหน้า เปลี่ยนชุดสีแล้วทั้งหน้าเปลี่ยนตาม ส่วนสีที่เลือกเองเป็น hex คงอยู่
- รูปเก็บแยกใน `assets` (ไม่อยู่ใน snapshot undo จึงไม่บวม) ถูกย่อให้ด้านยาวไม่เกิน 3508 px; PNG คง alpha

### ทดสอบ
```
npm run dev            # เทอร์มินัลหนึ่ง (ถ้าแก้โค้ดระหว่าง dev ให้เริ่ม server ใหม่ก่อนรันเทสต์ ไม่งั้น module ซ้ำสองชุด)
npm run test:e2e       # เครื่องมือแถบสารบัญ
npm run test:quote     # Quote Page Maker; ภาพทุก template × ทุก preset อยู่ใน docs/quote/ (contact-sheet.png)
```
ตรวจ: คอนทราสต์ preset >= 4.5:1, ขนาด PNG ทั้ง 3 แบบ, alpha, ZIP (ชื่อไทย + UTF-8 flag), พรีวิวเทียบ export ที่พิกเซล (ต่าง < 1%), auto-fit 10/300 ตัวอักษร, undo/redo/ลาก/ย่อ/หมุน/จัดชิด, บันทึก-เปิดโปรเจกต์, รีโหลดแล้วข้อมูลอยู่, รูป 4000×3000

### ข้อตัดสินใจที่สเปกคลุมเครือ (เลือกแบบง่ายสุด)
- Route เป็น hash (`#/quote`) ไม่ใช้ vue-router จะได้ deploy เป็นไฟล์สถิตได้ไม่ต้องตั้งค่า server
- เลือกได้ทีละ 1 องค์ประกอบ (ยังไม่มี multi-select); snap ทำตอนลากย้ายเท่านั้น ไม่ snap ตอนย่อขยาย/หมุน
- แก้ข้อความบนผืนผ้าใบ (ดับเบิลคลิก) แก้ได้เฉพาะข้อความหลัก ชื่อผู้กล่าวแก้ในแผงตั้งค่า
- โทนสีทับรูป (tint) เป็นชั้นสีโปร่งแสงธรรมดา (ไม่ใช้ mix-blend-mode) เพื่อให้ export ตรงพรีวิวแน่นอน จึงไม่ต้อง bake ด้วย canvas
- ขอบจางรูปใช้ CSS mask (radial / ทั้ง 4 ขอบ / ขอบล่าง)
- ขนาด 1080×1350: ย่อทั้งหน้าให้พอดีความสูงแล้ววางกึ่งกลาง (อัตราส่วนต่างกัน) ขอบข้างเติมด้วยสีพื้นแรกของหน้า
- เปลี่ยน template จะสร้างองค์ประกอบที่ template ทำไว้ใหม่ (เก็บข้อความ ผู้กล่าว รูป+ครอปเดิม) องค์ประกอบที่ผู้ใช้เพิ่มเองไม่ถูกลบ แต่การแก้ของชิ้นที่ template สร้างจะหายยกเว้นเนื้อหา; template ที่ไม่มีช่องรูปจะซ่อนรูปไว้แล้วนำกลับเมื่อสลับไป template ที่มีรูป
- เครื่องหมายคำพูดวาดจาก glyph ของฟอนต์ที่ฝังไว้ (4 สไตล์) ไม่ใช่ SVG เพื่อไม่ต้องพึ่งฟอนต์ระบบ
- ยังไม่ได้ทดสอบ: จอสัมผัสจริง (ใช้ pointer events + `touch-action:none`), Safari, การเปิด ZIP บน macOS จริง (ตรวจแค่ UTF-8 flag)
